# Positivus Landing Page

A responsive landing page built as part of my frontend development practice, based on a Figma design (`style-guide.md` + provided mockups).

## Overview

This project focuses on translating a design into semantic, accessible, responsive markup using modern CSS — Flexbox layout, CSS custom properties, and mobile-first media queries.

### Built with

- React + TypeScript (Vite)
- Semantic HTML5
- CSS (Flexbox, custom properties, mobile-first responsive design)
- Google Fonts (Space Grotesk, Outfit)

### What I focused on

- Matching the design precisely using Figma inspector values (spacing, colors, typography)
- Keyboard-accessible navigation (visible focus states)
- Component layout with Flexbox — navbar alignment, gap-based spacing instead of margin hacks
- Responsive behavior across mobile / tablet / desktop breakpoints

## Getting started

```bash
npm install
npm run dev
```
